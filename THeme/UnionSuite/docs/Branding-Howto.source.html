APPLY YOUR BRANDING

Update your site’s branding

Once you’re happy with the preview, follow these steps to apply your colours in iMIS.

Branding.css

Replace this file’s contents with the CSS copied from this page. It holds your generated branding settings.

Override.css

You can also edit this file to add client-specific CSS rules that override the base theme. Keep these custom rules here so replacing Branding.css does not remove them.

  1. Choose your colours and copy the CSS

    Adjust the Brand colours palette and any optional settings, then check the live examples. In Your branding CSS above, click Copy CSS. Keep this page open until you have pasted the code into your file.

  2. Open Themes in iMIS

    In the Staff site, open Theme Builder → Themes from the left-hand menu.

  3. Download your client theme

    Select UnionSuite-Client, then click Download in the toolbar. Your browser will download a ZIP file.

    Use UnionSuite-Client for this update. UnionSuite-Core contains the shared base theme.

  4. Replace the branding code

    Extract the downloaded ZIP file and open Branding.css in a text editor, such as Notepad. Select all of its contents, paste the CSS you copied from this page, and save the file.

    If you want to change other client-specific styles, edit Override.css as well. Otherwise, leave its contents as they are.

  5. Create the updated ZIP file

    Zip the updated theme files back together, keeping the same folder structure as the original download. Include both Branding.css and Override.css, and avoid adding an extra folder around them.

  6. Upload the new version and save

    Return to Theme Builder → Themes. Select UnionSuite-Client and click Edit.

    Under Upload new version, click Select and choose your updated ZIP file. Click Save to finish.

    Refresh a page on your site and check that your new colours appear as expected.
