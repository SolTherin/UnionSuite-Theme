Design tokens

Defaults are iMIS Orion's own palette, measured from 99-Orion.css. Contrast figures are measured against both grounds a staff page actually has: card white and the page ground #eeeeef.

Captions show Orion's reference value, not the live one. If a swatch does not match its caption, a client rebrand is active — which is exactly what you want to see when testing one.

Rebrand check

Everything above is driven by the five seeds. Add this to the client sheet and reload: brand, accent, links, borders and dark surfaces should all move; the status row should not. The second block shows how to pin a single derived stop back to an exact value.

:root {
  --seed-primary:       #4a2f7a;
  --seed-primary-light: #b39ddb;
  --seed-accent:        #d4a017;
  --seed-accent-alt:    #e0704f;
  --seed-neutral:       #5b5560;
}

/* pin one derived stop, if a client insists */
:root { --teal-500: #007ea8; }
