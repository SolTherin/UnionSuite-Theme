Try it

Type a note or edit the contact details, switch sections and return. The original controls stay mounted, so their values survive. Use Left/Right, Home and End on the tabs; Tab moves into the selected section.

Light and navy use the same layout. On small screens, the tab row scrolls horizontally. Sticky mode keeps the navigation at the top while scrolling.

This prototype loads all sample sections at the start. It demonstrates visibility switching, not lazy loading, server postback recovery or automatic iMIS zone discovery.
