How client-defined colours would work

The IQA formula supplies a status label and a hex colour independently. No fixed list of membership statuses is required. Status text stays white. Colours that are too light are darkened to provide at least 4.5:1 contrast, with the same display colour used for the pill and strip. The entered client hex remains unchanged. Written labels ensure colour is never the only cue.

The initials treatment uses the adjusted display colour on white, with the same colour on its ring. Try your own hex value above before choosing a direction. These are visual state samples; scroll-triggered collapsing and action handlers remain in the shared banner.
