What we’re choosing

Option A is the lightest standalone treatment. Option B provides the closest match to existing horizontal CCOs. Option C feels more like a compact view selector. Banner navigation can keep its navy adaptation whichever standalone option we choose.

These are visual proposals. Shared appearance does not require shared loading behaviour: native CCO retains iMIS navigation; standalone sections can switch locally.
